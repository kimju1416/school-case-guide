# 사안 처리 길잡이 — 조사 규칙과 결과 형식

## 목적
교사(특히 신규·저경력·처음 담임)가 학교에서 사안이 "터졌을 때" 폰으로 열어 바로 따라 하는 길잡이.
대상 지역: 경상북도(경북교육청) 중·고 위주, 초등도 해당되면 함께. 오늘 날짜 2026-09-24.

## 조사 규칙 (반드시)
1. **공식 원문만 근거로 쓴다**: 국가법령정보센터(law.go.kr) 법령·시행령·고시, 교육부·교육청 매뉴얼/가이드북(PDF), 보건복지부·경찰청·질병관리청·개인정보보호위원회 등.
   블로그·언론은 "변경 사실 확인용 실마리"로만 쓰고 근거로 적지 않는다.
2. **5년 넘은 자료 금지** — 2021년 이후 발행본만. 발행연도가 확인 안 되면 쓰지 않는다. 최신판(2025·2026)이 있으면 반드시 최신판.
3. 법이 최근 바뀐 곳(학교폭력 2024.3 개정, 교권 5법 2023~2024, 생활지도 고시 2023.9, 109 자살예방상담전화 2024.1, 딥페이크 성범죄 2024.10 개정 등)은 **현재 시행 중인 조문**으로 확인. 조문 번호까지 적는다.
4. 숫자(기한·일수·시간·과태료·전화번호)는 원문에서 직접 확인한 것만. 확인 못 한 것은 적지 말고 `uncertain`에 적는다. **지어내지 않는다.**
5. PDF는 WebFetch가 못 읽으면 curl로 받아(학교망 SSL 문제 시 `curl --ssl-no-revoke -L`) python pdfplumber로 텍스트를 뽑아 읽는다. 받은 파일은 `C:/Users/USER/Downloads/school-case-guide/research/src/` 에 둔다.
6. 저작권: 원문을 길게 베끼지 말고 절차를 우리 말로 요약한다(짧은 용어·조문 번호는 괜찮음).

## 결과 형식
사안 하나당 JSON 파일 하나: `C:/Users/USER/Downloads/school-case-guide/research/<id>.json` (UTF-8, 들여쓰기 2)

```json
{
  "id": "school-violence",            // 영문 kebab
  "title": "학교폭력 인지·신고",        // 짧은 이름
  "aka": ["학폭", "때렸어요", "괴롭힘", "왕따"],  // 교사·학생이 실제로 쓰는 검색어 8~15개
  "category": "학생 간 사안",          // 학생 간 사안 | 학생 보호·위기 | 교원 보호 | 안전·보건 | 행정·정보
  "urgency": "즉시",                  // 즉시(생명·신체·범죄) | 당일 | 며칠 안
  "roles": ["담임", "목격 교사", "학교폭력 책임교사", "교감"], // 이 사안에서 할 일이 있는 사람
  "summary": "한두 문장. 이 사안이 무엇이고 핵심 원칙이 무엇인지.",
  "first": ["지금 당장 할 일 3~5개, 짧은 명령문"],
  "steps": [
    {"when": "인지 즉시", "who": "알게 된 교직원", "what": "…", "detail": "…(선택)", "basis": "학교폭력예방법 제20조(선택)"}
  ],
  "deadlines": [{"what": "…", "limit": "…(예: 인지 후 즉시 / 14일 이내)", "basis": "…"}],
  "dont": ["하지 말 것 3~6개 — 실제로 교사들이 자주 하는 실수"],
  "contacts": [{"name": "학교폭력 신고", "tel": "117", "note": "24시간"}],
  "forms": ["필요한 서식·기록 이름(매뉴얼 부록 서식 번호 있으면 함께)"],
  "law": [{"name": "학교폭력예방 및 대책에 관한 법률", "article": "제20조(학교폭력의 신고의무)", "point": "누구든지 학교폭력 현장을 보거나 그 사실을 알게 된 자는 학교 등 관계기관에 즉시 신고"}],
  "faq": [{"q": "교사들이 실제로 헷갈리는 질문", "a": "원문 근거 있는 답"}],
  "record": "생활기록부·나이스·보고 공문 관련 핵심(없으면 빈 문자열)",
  "sources": [{"title": "2026 학교폭력 사안처리 가이드북", "publisher": "교육부", "year": 2026, "url": "…"}],
  "verified": "2026-09-24",
  "uncertain": ["확인 못 했거나 지역·학교마다 다른 것"]
}
```

단계(steps)는 실제 흐름 순서대로 6~14개. faq는 3~8개.
끝나면 짧게 보고: 만든 파일 목록, 사안별 핵심 출처(제목·연도), 확인 못 한 것.

## 추가 규칙 (2026-09-24 형님 지시) — 끝까지, 최대한 자세히
"지금 할 일"에서 멈추지 말고 **사안의 처음부터 완전히 끝날 때까지** 다 적는다.
예) 학교폭력: 인지 → 신고·접수 → 분리 → 보고 → 사안 조사(전담조사관 조사 방식·확인서·면담·증거) → 전담기구 심의 → 자체해결 또는 심의위원회 요청 → 심의위원회(구성·개최 기한·출석·의견진술·회의록 열람) → 조치 결정(1~9호·피해학생 보호조치) → 통보 → 조치 이행·특별교육·미이행 시 → 생기부 기재 → **불복(행정심판·행정소송·집행정지 — 청구 기간·청구처·누가 할 수 있는지)** → 재심·재조치 → 졸업 시 삭제 심의 → 관계회복.
교권·성폭력·아동학대·안전사고(공제 보상 불복: 재심사 등) 등도 같은 수준으로 수사·심의·결정·불복·종결까지.

- `steps`는 12~30개로 늘려도 된다(전체 수명주기).
- 새 칸 `deep`: 과정별 깊이 보기 설명. `[{"title":"사안 조사는 이렇게 진행된다","body":["문단1","문단2"],"basis":"근거"}]` 3~8개.
- 새 칸 `tables`: 비교표. `[{"title":"가해학생 조치 1~9호","head":["호","조치","생기부","삭제 시기"],"rows":[["1호","서면사과","…","…"]],"note":"출처·주의"}]` 1~4개.
- 불복 절차는 반드시: 청구 기간(안 날부터 90일 등), 청구처, 청구인, 집행정지 여부 — 원문 확인한 것만.
- 🔴 `steps` 각 항목에 `"stage"` 칸을 꼭 넣는다. 값은 아래 7개 중 하나(흐름도 가로축):
  "알게 됨·신고" | "초기 대응" | "조사·확인" | "심의·결정" | "조치·이행" | "불복·구제" | "종결·사후"
  (그 사안에 없는 단계는 안 써도 된다. steps 순서는 실제 시간 순서.)
