## 확인됨(주요)
- emergency-medical: 발견(Check) → 119·AED·보건교사(Call) → 가슴압박·AED·상황별 처치(Care) → 인계·보고(보건교사 → 교감, 담임 → 교감, 교감 → 교장) → 기록 → 공제 → 재발 대비. 가이드라인 그림 1-1 설명·표1-4·표1-5와 순서·주체 맞음. 심장정지 시 «최초발견자가 먼저 119·AED 요청 후 지체 없이 CPR»(제1장 Ⅲ-2) 일치.
- safety-accident: 3C → 보호자·교감 보고 → 동행 → 제10조 제4항 즉시 보고 → 기록 → 제44조 제2항 통지 → 제41조의2 안내 → 청구 → 14일 결정 → 심사 90일 → 재심사 90일 → 제64조 60일 합의 간주 → 장해·간병 → 시효 3년. 조문 원문(safelaw.txt)과 맞음. summary·deadlines·tables·faq 서로 일치.
- field-trip-accident: 구조 → 학교장 보고 → 교육청 즉시 보고 → 창구 일원화 → 일정 결정 → 공제 → 불복. summary 순서와 steps 일치, 시·도 예시 표시 유지.
- infectious-disease: 대응 1→2→3단계→복구가 매뉴얼 표3-4·3-7·3-10·3-17 순서와 맞음. 8종 보건소 신고, 제14조의3 즉시 보고 일치.
- food-poisoning: 제6차 표2 1~6단계 순서와 steps 대응, 법정 보고(1명도 지체 없이)와 2명 이상 지침 기준이 summary·first·steps·deadlines·faq·dont에서 일관.
- fire-earthquake: 지진 2단계(머리 보호) → 대피·인원 확인 → 3단계 대책 회의·보고·수업 결정·귀가 → 4단계 복구 순서 일치.
- privacy-leak: 인지 → 확산 차단 → 내부 보고 → 범위 확인 → 통지(72시간) → 신고 판단·신고 → 조사·재발방지 → 제재 → 구제. 안내서 대응 흐름(Ⅰ~Ⅴ)과 맞음. 72시간 기산점(알게 된 때) 전 칸 일치.
- drugs-substance: 119 → 소지품 조사·분리보관 → 학교장 보고·보호자 통지(고시 제12조 제6항) → 사실 확인·신고 → 1342·치료보호 → 징계·재심(15일/10일, 30일, 60일). summary·first 일치.
- 파일 간 공통 사실: 119·112·1388·1577-0199·1342, 행정심판 90/180일·행정소송 90일/1년(privacy-leak), 학교안전공제 90·90·60일(safety·field-trip·fire 세 파일 동일), 교직원 응급처치 교육 «매년 실습 2시간 포함 3시간»(emergency·safety 동일).

## 제안(원문 근거가 부족하거나 표현만 다듬을 것 — 고치지 않음)
1. field-trip-accident first[1] «짧은 시간 안에 못 찾으면 112» — «짧은 시간» 기준은 원문에 없고, dont «신고를 늦추지 않는다»와 steps «112에 신고한다»와 어긋나 보임. «찾기와 함께 112 신고 여부를 곧바로 정한다» 식으로 맞출 것을 제안(인천 매뉴얼은 «실종 시 안내방송 및 공항 경찰에 신고»만 있음).
2. privacy-leak dont «유출 결과를 전체 공지로 알리지 않는다» — 시행령 제39조 제3항은 연락처를 모를 때 홈페이지 30일 게시로 갈음을 허용하고 안내서도 홈페이지 공지를 든다. «유출된 내용(명단·파일)을 전체 공지에 다시 싣지 않는다»로 뜻을 좁힐 것을 제안.
3. drugs-substance steps «분리 보관»·deep의 «봉인 보관했다가 경찰에 넘기는 것이 안전하다» — uncertain에 «공식 원문 못 찾음»으로 적혀 있는데 본문은 권고형으로 남아 있음. 권고임을 밝히거나 소속 교육청·경찰 안내에 따르도록 완화 제안.
4. food-poisoning first[0] «증상 학생을 보건실로 보내» — 노로바이러스 등 감염성일 수 있으므로 감염병 매뉴얼(의심 환자 교내 혼자 이동 금지, 담임 동행) 표현과 맞출 것을 제안.
5. food-poisoning — 제6차 표2 2단계 «식중독 조기경보시스템 현행화(당월 납품업체 입력 확인, 식단표 등 제공)»가 steps에 없음. 핵심 신고 절차는 아니라 추가하지 않음.
6. fire-earthquake steps «머리 보호·책상 아래로…» — 매뉴얼의 «각 학급 전원 차단(주간)»이 빠짐. 작은 누락이라 제안만 함.
7. emergency-medical steps «기록» stage가 «조사·확인» — 기록 행위라 «조치·이행»이 더 맞을 수 있으나 판단이 갈려서 두었음.

## 가장 중요한 것
- 감염병 유행의심 기준 ②(다른 반이라도 이동수업·급식 등 공통 노출이면 유행의심)가 빠져 있어 보탰다 — 빠져 있으면 3단계로 올려야 할 상황을 놓칠 수 있었다.
- 응급 파일의 «치료가 필요하면 공제 통지»는 법(제44조 제2항 «발생한 때 지체 없이»)보다 조건을 좁혀 교내 안전사고 파일과 서로 어긋났다 — 바로잡았다.
- 감염병 자체 휴업 뒤 «지체 없이 관할청 보고»(시행령 제47조 제3항) 의무가 빠져 있어 넣었다.
