# 7차 전수 재검수 마감 기록

- 기준일: 2026-09-24
- 대상: 21개 학교 사안 전체(요약·첫 행동·세부 단계·기한·금지사항·표·FAQ·심화 설명·법령·연락처·출처·확인 필요 항목), 모바일 업무 흐름 및 출처 링크.
- 범위: 앞선 1~6차 교차검수와 각 사안별 원문 대조 기록을 토대로, 21개 본문을 다시 훑고 발견한 범위 과장·오래된 기준·단일 지역 지침의 전국화·현행 법령과의 혼동을 수정했다. 모든 문장을 오류가 절대 없다고 보증하는 법률의견은 아니다. 지역별 보고서식·학칙·운영기준이나 사건별 판단은 해당 교육청·학교·관계기관의 최신 원문으로 확인하도록 표시했다.

## 이번 마감에서 추가로 바로잡은 핵심

- 아동학대 의심: 학교장은 교육기관 내 보고와 법정 신고를 구분하도록 수정. 응급조치 72시간 범위를 해당 조치로 한정하고 연장 요건을 구체화. 2026 학생부 기재요령의 지자체 분리보호와 그 밖의 결석을 구분.
- 학생생활지도: 개별학생교육지원의 장소 선택지와 보고·보호자 통지 요건을 현행 시행령에 맞춤. 자동 면책처럼 읽히는 문구 제거.
- 미인정결석: 인가 대안학교·등록 대안교육기관·미등록 시설, 취학 유예와 정원 외 학적관리 절차를 구분.
- 학교폭력·성폭력·딥페이크: 가이드북상 학교 대응 절차와 청소년성보호법상 법정 신고의무의 적용범위를 분리.
- 학교급식 식중독: 2026 제6차 위생관리 지침서 원문에 직접 대조. 지침상 2명 동시 발생 학교 보고 기준과 식품위생법상 1명도 가능한 집단급식소 법정 보고를 별도로 표시. 보존식과 조사 순서를 최신판에 맞춤.
- 성폭력 초기 대응: 응급치료를 우선하고, 증거 보존은 피해자의 선택과 상황을 고려하도록 수정.

## 검증 결과

- 연구 JSON 23개 파싱 성공(사안 21개와 공통 출처·연락처 파일), 사이트 빌드 성공(사안 21건, 연락처 12건, 공통 출처 34건, 처리 단계 421개).
- 생성 HTML 인라인 JavaScript 2개 구문 검증 통과, viewport 메타 및 모바일 목록 기본 선택 확인. 390px 모바일 렌더링에서 가로 흐름도 대신 세로 단계 목록 표시 확인.
- 사안 자료에 연결된 고유 공식 출처 URL 127개를 GET으로 확인, 모두 HTTP 2xx 응답.
- 지역·학교별로 달라 전국 단일 절차로 확정할 수 없는 사항은 각 사안의 `uncertain`과 본문 확인 조건에 남겼다. 이는 사실 오류로 확인된 항목이 아니라 소속기관 원문 확인이 필요한 범위다.
